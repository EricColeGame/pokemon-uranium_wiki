## Qu'est-ce que la fonctionnalité Cadeau Mystère dans Pokemon Uranium ?

Le Cadeau Mystère est une fonctionnalité de distribution intégrée qui remet des Pokémon cadeaux et des objets spéciaux, généralement pour commémorer un jour férié, un anniversaire du jeu ou un jalon communautaire du projet de fan. Chaque distribution est conditionnée sous forme de Carte Miracle — un petit bon numérique qui enregistre ce que vous avez reçu et quand. Vous réclamez la carte depuis l'écran titre, puis vous retirez la créature ou l'objet réel auprès d'un PNJ de boutique dans votre sauvegarde.

Comme les développeurs livrent ces cadeaux via le client de jeu lui-même plutôt que par un service en ligne de console, il n'y a rien à souscrire et aucun code de rédemption à saisir. Vous mettez simplement le jeu à jour, ouvrez le menu et réclamez.

| Détail de la fonctionnalité | Fonctionnement |
| --- | --- |
| Où réclamer | Menu principal → Cadeau Mystère |
| Condition de déblocage | Vous devez avoir reçu votre Pokédex du Professeur Bamb'o |
| Où récupérer | Dans n'importe quelle PokéMart, auprès du PNJ à gauche en tenue de facteur vert |
| Coût | Gratuit |
| Contenu typique | Pokémon événementiels, objets tenus, objets d'évolution, Super Bonbons |
| Sauvegarde requise | Vous devez entrer dans le jeu et sauvegarder après avoir réclamé |
| Compte en ligne nécessaire | Non |

## Comment réclamer un Cadeau Mystère dans Pokemon Uranium

Le processus est court, mais il comporte une étape qui piège presque tout le monde : la sauvegarde. Suivez la séquence ci-dessous dans l'ordre et vous n'aurez rien à réclamer de nouveau.

| Étape | Action | Notes |
| --- | --- | --- |
| 1 | Progressez jusqu'à ce que le Professeur Bamb'o vous donne le Pokédex | L'option de menu reste masquée avant ce point |
| 2 | Quittez vers le menu principal (avant de charger une sauvegarde) | L'option Cadeau Mystère se trouve sur l'écran titre |
| 3 | Sélectionnez Cadeau Mystère et acceptez la ou les Cartes Miracle | Vous pouvez réclamer plusieurs cartes à la fois |
| 4 | Entrez dans votre sauvegarde et sauvegardez le jeu | C'est l'étape que les gens sautent — ne la sautez pas |
| 5 | Rendez-vous dans n'importe quelle PokéMart | Chaque PokéMart utilise le même PNJ de livraison |
| 6 | Parlez au PNJ à gauche en tenue de facteur vert | C'est le livreur de tous les cadeaux |
| 7 | Récupérez votre Pokémon ou vos objets | Les statistiques aléatoires sont tirées ici même |

### Pourquoi l'étape de sauvegarde est si importante

Les développeurs ont intégré une règle spécifique à cette fonctionnalité : si vous voulez réclamer un cadeau sur plusieurs fichiers de sauvegarde, ou si vous prévoyez de faire des soft-resets pour obtenir un meilleur Pokémon, vous devez entrer dans le jeu et sauvegarder après avoir réclamé depuis le menu principal. Si vous changez de fichier de sauvegarde ou fermez le programme sans le faire, le jeu n'enregistre pas le cadeau comme réclamé, et vous devrez le réclamer de nouveau. Ce n'est pas un bug — c'est ainsi que l'indicateur de distribution est écrit.

### Si votre Pokémon cadeau semble incorrect

Les rapports de la communauté mentionnent un problème cosmétique récurrent : un Pokémon cadeau qui arrive sans son sprite spécial. La solution standard est d'exécuter le patcheur. Dans le menu principal, utilisez l'option Check For Updates pour que le client télécharge les derniers fichiers de données, puis récupérez le cadeau à nouveau. Garder le jeu patché garantit aussi que vous voyez la distribution la plus récente plutôt qu'une carte expirée.

## Soft-reset de votre cadeau : ce qui est aléatoire et ce qui est fixe

C'est la partie qui rend le système de Cadeau Mystère de Pokemon Uranium véritablement utile pour les joueurs à l'esprit compétitif. Les développeurs ont divisé les données en deux étapes : la carte elle-même est fixée au moment où vous la réclamez, mais les traits aléatoires du Pokémon ne sont décidés qu'au moment où vous le recevez réellement du livreur. Cet écart est votre fenêtre pour relancer les dés.

| Décidé lorsque vous réclamez dans le menu principal | Décidé lorsque vous récupérez à la PokéMart |
| --- | --- |
| Quel cadeau vous recevez | Nature |
| La Carte Miracle et sa date enregistrée | Talent |
| L'objet tenu et les capacités fixes de la distribution | Caractère chromatique |
| Le niveau, la Ball et le numéro d'ID fixes | Sexe (expérience joueur) |
| — | Valeurs individuelles (expérience joueur, non documentées officiellement) |

Une routine pratique de soft-reset ressemble à ceci :

- Réclamez le cadeau depuis le menu principal, puis entrez dans votre sauvegarde et sauvegardez le jeu.
- Placez-vous directement devant le livreur et sauvegardez une seconde fois pour que votre point de contrôle soit juste là.
- Parlez-lui et vérifiez l'écran de résumé. Si la nature, le talent ou la couleur ne conviennent pas, réinitialisez le jeu et parlez-lui de nouveau.
- Répétez jusqu'à obtenir ce que vous voulez — vous n'avez jamais à retélécharger ni à réclamer la carte de nouveau.

Comme le tirage a lieu à la récupération, cette méthode est rapide. La plupart des joueurs rapportent qu'un cycle de réinitialisation prend bien moins d'une minute une fois qu'ils sont devant le PNJ.

## Conseils, rapports de la communauté et dépannage

Quelques habitudes séparent les joueurs qui collectionnent tous les cadeaux de ceux qui les perdent :

- Réclamez sur chaque fichier de sauvegarde qui vous importe. Chaque fichier a son propre indicateur de réclamation, mais chacun a besoin de sa propre sauvegarde après réclamation.
- Réclamez tôt dans la fenêtre. Les distributions tournent, et une carte non réclamée peut devenir indisponible.
- Vérifiez les mises à jour avant une session de soft-reset pour que les données de sprite et les indicateurs de cadeau soient à jour.
- Gardez l'horloge de votre système à l'esprit — la date de réception sur la Carte Miracle reflète la date de votre ordinateur.
- Faites une copie de sauvegarde de votre fichier avant les longues sessions de réinitialisation, juste au cas où.

| Problème | Cause probable et solution |
| --- | --- |
| Cadeau Mystère est absent du menu principal | Vous n'avez pas encore reçu le Pokédex |
| Le livreur n'a rien pour vous | Vous avez réclamé la carte mais jamais sauvegardé ; réclamez de nouveau, puis sauvegardez |
| Le cadeau a disparu après un changement de sauvegarde | La réclamation n'a pas été enregistrée ; réclamez-le de nouveau et entrez dans le jeu |
| Le Pokémon n'a pas de sprite spécial | Exécutez le patcheur via Check For Updates dans le menu principal |
| La date de la Carte Miracle semble incorrecte | La date suit l'horloge de votre système, pas le serveur |

Pour les informations de téléchargement et de mise à jour les plus récentes, consultez le [site officiel de Pokemon Uranium](https://pokemon-uranium.com/) avant de dépanner manuellement — un client obsolète est la cause de la plupart des comportements étranges signalés par les joueurs.

## FAQ

**Comment débloquer l'option Cadeau Mystère de Pokemon Uranium ?**
Vous devez atteindre le moment de l'histoire où le Professeur Bamb'o vous donne votre Pokédex. Tant que cela n'est pas arrivé, l'entrée Cadeau Mystère reste masquée dans le menu principal, même si une distribution est active.

**Un Pokémon obtenu par Cadeau Mystère peut-il être shiny ?**
Oui. Le caractère chromatique, ainsi que la nature et le talent, sont tirés au moment où vous recevez le Pokémon du livreur de la PokéMart. Sauvegardez avant de lui parler, puis réinitialisez et réessayez jusqu'à obtenir le résultat souhaité.

**Puis-je réclamer le même cadeau sur plusieurs fichiers de sauvegarde ?**
Oui, mais vous devez entrer dans le jeu et sauvegarder sur chaque fichier après avoir réclamé depuis le menu principal. Sauter cette étape signifie que le cadeau n'est pas enregistré, et vous devrez le réclamer de nouveau.

**Ai-je besoin d'une connexion Internet ou d'un compte pour utiliser la fonctionnalité Cadeau Mystère de Pokemon Uranium ?**
Aucun compte et aucun code ne sont nécessaires. Les cadeaux sont livrés via le client de jeu, donc exécuter Check For Updates est ce qui vous maintient aligné avec la distribution actuellement active. L'expérience des joueurs suggère que vérifier les mises à jour est l'étape de dépannage la plus fiable lorsqu'un cadeau semble cassé.
